# Safar-e-Pakistan — Travel Website

A responsive travel and tourism website showcasing the beauty, culture, and destinations of Pakistan, built with HTML, CSS, and JavaScript.

## Run it

Open `index.html` in a browser. There is no build step.

## What it includes

- Destination highlights from across Pakistan, with photos in `Assets/`.
- Interactive filtering and trip-planning features in `script.js`, styled by `style.css`.
